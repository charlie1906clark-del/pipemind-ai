# Independent review scope

This review evaluates the executable orchestration and link-acquisition controls, the actual bounded federal pilot, and the claims made about their operation. It does not certify a newly discovered fraud, reward eligibility, nationwide coverage or an unattended model service.

The reviewer owns only this folder. Producer corrections must be applied by the responsible producer and then tested again. Final review records will pin the exact inspected artifacts; this scope document is not a completion receipt.

| Area | Independent challenge |
|---|---|
| Persistence | Interrupted work can resume without erasing attempts, evidence, budgets or review history. New evidence can reopen a declared gap within remaining limits. |
| Ownership | Stale leases, duplicate claims and self-review cannot advance the task. Actor labels are declarations, not authenticated people. |
| Evidence | File bytes must match their digest; replaying an ID with different content fails. Source authenticity remains a separate review obligation. |
| Dependencies | A producer's submission does not unlock dependent work before independent acceptance. |
| Acquisition | Only approved public HTTPS destinations; each redirect and actual connection checked. Credentials, private addresses and unexpected hosts excluded. |
| Source instructions | Retrieved text, scripts, links and model-directed language are treated as evidence data, never authority to run tools or change scope. |
| Budgets | Successful and failed requests count; redirects, oversized bodies, retries and interrupted attempts cannot bypass limits. |
| Price | Exact item, unit, pack, quantity, date and commercial terms required. Repeat premiums need independent references; no reverse-engineered 12% baseline. |
| Meaning | Ceiling, obligation, order, invoice and payment are distinct. A premium is not a personal benefit or recoverable loss. |
| Identity | Exact business identifiers and dated professional roles; names alone do not establish identity, ownership, influence or misconduct. |
| Coverage | A bounded selected sample remains a sample; all inclusion, exclusion, failure and continuation states reported. |
| Operation | Executed session work, deterministic tooling, task plans and deployed/background model services are reported separately. |

A useful result can reject a suspected comparison or remain unresolved. No review criterion requires a positive fraud finding. Two exact official pilot records will be rechecked if available, within a six-request independent acquisition limit.
