# PipeMind AI – 30-Day Fast-Track Plan

**Period:** 31 July – 30 August 2026

## Overall Goal
By Day 30 you will have:
- A clean, professional GitHub repository
- Deep knowledge of all 6 modules
- One working module prototype started
- At least 8–12 real conversations with people in the industry
- A clear next 90-day plan

## Week 1 – Foundation (Days 1–7)
Focus: Clean structure + deep learning

- Organise GitHub exactly as defined in the architecture document
- Study every research and build-plan file thoroughly
- Set up your Obsidian vault using the structure in `02-obsidian-brain.md`
- Write your own one-page vision in simple language
- Create the first version of your target outreach list

## Week 2 – First Outreach + Choose Module (Days 8–14)
Focus: Talk to real people + start building

- Send 8–12 personalised LinkedIn messages per day (quality over quantity)
- Target: SCARLET related people, Hydrogen UK, Energy Systems Catapult, National Grid Innovation, Arup, Mott MacDonald, academic authors
- Choose either Module 1 (Route) or Module 3 (Safety) as your first build target
- Begin coding the core of that module

## Week 3 – Momentum (Days 15–21)
Focus: Conversations + technical progress

- Follow up with everyone who replied
- Offer small pieces of value (quick analysis, shared research insight)
- Continue daily development on the chosen module
- Log every conversation and what you learned

## Week 4 – Conversion (Days 22–30)
Focus: Turn interest into next steps

- Push for short calls or feedback sessions
- Improve the module based on real feedback
- Prepare a simple demo
- Write a full review of the 30 days and set the next 90-day goals

## Daily Rhythm (recommended)

- 09:00–11:30 Technical work / learning
- 11:30–13:00 Outreach and follow-ups
- 14:00–16:30 Building or deeper study
- 16:30–17:30 Admin, notes, planning next day
- Evening: Short reflection in Obsidian
