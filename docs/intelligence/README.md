# PipeMind Intelligence Core

This folder is the living brain for the competitive intelligence product.

## Structure

- `company-profiles/` → One Markdown file per company (living profiles)
- `templates/` → Master templates
- `briefs/` → Generated weekly and company-specific briefs
- `agent/` → Instructions for the automated agent

The automated agent reads from this structure, updates profiles, and generates differentiated briefs.
