# Module 5 Research – Digital Twin Viewer

## Purpose
Provide a living digital representation of the hybrid pipeline for both design review and later operational use.

## Design-Phase Twin
- 3D or schematic view of the corridor and stations
- Click any element to see design values
- Layer toggles (safety zones, sensors, land ownership)
- Multi-user comments and versioning

## Operational Twin (later)
- Live sensor data (temperature, pressure, flow, electrical)
- Anomaly detection
- Simple predictive alerts
- Preparation for XR / advanced visualisation

## Technology Notes
- Start browser-based (Three.js or similar)
- Keep the data model clean so higher-fidelity physics can be added later
- Learn from existing energy digital twin platforms (Siemens, Bentley iTwin, AVEVA, etc.) while remaining specialised
