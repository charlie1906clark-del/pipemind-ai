# Module 5 – Digital Twin Viewer
## Super-Detailed Build Plan

### Goal
A clear visual and data twin of the planned (and later operating) hybrid pipeline.

### Phase 1 – Design Twin
1. Accept geometry and data from previous modules
2. Render corridor and stations on a map + simple 3D/schematic view
3. Click-to-inspect any segment or station
4. Layer controls and basic annotation

### Phase 2 – Data Model
5. Clean, versioned data model that can grow
6. Store design assumptions with the twin
7. Prepare hooks for live data later

### Phase 3 – Operational Readiness
8. Sensor data interface (OPC-UA / MQTT / REST)
9. Status colouring and simple alerts
10. Export and sharing capabilities

### Definition of Done for v1
- A user can understand the full planned system in under 10 minutes of exploration
- The same model is ready to become operational later
