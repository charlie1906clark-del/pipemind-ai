# Module 5 – Digital Twin Viewer
## Super-Detailed Build Plan

### Goal of v1
A clear visual and data twin that lets a user understand the full planned system quickly and that is ready to accept live data later.

### Phase 1 – Design Twin
1. Ingest geometry and attributes from previous modules
2. Render corridor and stations on an interactive map + simple schematic/3-D view
3. Click-to-inspect any element
4. Layer controls and basic multi-user annotation

### Phase 2 – Data Model
5. Clean, versioned data model designed for growth
6. Store design assumptions with the twin
7. Prepare well-defined hooks for live sensor data

### Phase 3 – Operational Readiness
8. Sensor interface layer (OPC-UA, MQTT or REST)
9. Status colouring and simple alert rules
10. Sharing and export capabilities

### Definition of Done
- New user can understand the planned system in under 10 minutes
- Same model can later become the operational twin without major rewrite
