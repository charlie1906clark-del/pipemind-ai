# PipeMind AI – Grok Skills

Seven specialist skills have been created to accelerate development and decision-making:

| Skill Name | Purpose |
|------------|---------|
| `pipemind-master` | Overall strategy, architecture, prioritisation, business growth |
| `pipemind-route` | Module 1 – Smart Route Planner |
| `pipemind-cooling` | Module 2 – Cooling & Cryogenics |
| `pipemind-safety` | Module 3 – Safety & Risk Simulator |
| `pipemind-cost` | Module 4 – Cost & Business Case |
| `pipemind-twin` | Module 5 – Digital Twin Viewer |
| `pipemind-reports` | Module 6 – Report & Compliance |

These skills live in the local Grok skills directory and encode the full project knowledge, build plans and decision rules.

To use them, simply refer to the module or ask strategy questions – the correct skill will activate and keep advice consistent with everything we have developed.
